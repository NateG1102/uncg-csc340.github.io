StockSyncer

StockSyncer is a full-stack stock analytics dashboard that enables users to explore real-time market data, institutional ownership trends, and short-term price movements. The platform integrates financial APIs and AI-powered chat functionality to deliver stock-specific insights through interactive visualizations and dynamic data filtering. Technologies used include Spring Boot, REST APIs, JavaScript, and data visualization tools.
